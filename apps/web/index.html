👁️

Transparency

✓ Can do

  • Send messages on your behalf (with approval)
  • Execute trades via DEX aggregators
  • Automate browser tasks
  • Run sandboxed shell commands
  • Remember and search information
  • Work fully local (except AI calls)

✗ Cannot do

  • Access data without explicit approval
  • Send funds without L3+ permission
  • Run code outside sandbox
  • Store secrets unencrypted
  • Send telemetry (fully local)
  • Work offline for AI inference
