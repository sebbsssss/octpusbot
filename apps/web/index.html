Get Started

Install in 60 Seconds

Octpus runs locally on your machine. Your data stays yours.

1

Clone the repo

Get the Octpus codebase from GitHub.

git clone https://github.com/octpusbot/octpus.git
cd octpus
2

Install dependencies

Use bun for fastest installation.

bun install
3

Set your API key

Only Anthropic key is required. Everything else is optional.

# Required for AI brain
export ANTHROPIC_API_KEY="sk-..."

# Optional: Telegram bot
export TELEGRAM_BOT_TOKEN="..."
4

Start Octpus

Launch the CLI and start chatting!

bun run octpus

Be Informed

What Octpus Can & Cannot Do

Transparency about capabilities and limitations.

✅

What Octpus CAN Do

  • ✓ Send messages via Telegram, Discord, WhatsApp, Slack
  • ✓ Create and manage crypto wallets (EVM + Solana)
  • ✓ Execute token swaps via DEX aggregators
  • ✓ Browse websites, take screenshots, extract data
  • ✓ Remember information and search semantically
  • ✓ Execute shell commands in a sandbox
  • ✓ Read text from images (OCR), scan QR codes
  • ✓ Run scripts (bash, Python, Node.js)
  • ✓ Track portfolio value and get price alerts
  • ✓ Work completely offline (except AI calls)
❌

What Octpus CANNOT Do

  • ✗ Access your data without your explicit approval
  • ✗ Execute high-risk actions without 2FA confirmation
  • ✗ Send funds without permission (L3+ requires approval)
  • ✗ Run arbitrary code outside the sandbox
  • ✗ Access system files like /etc/passwd
  • ✗ Execute destructive commands (rm -rf, etc.)
  • ✗ Store your secrets unencrypted
  • ✗ Phone home or send telemetry (fully local)
  • ✗ Work without an internet connection for AI
  • ✗ Replace human judgment on important decisions
